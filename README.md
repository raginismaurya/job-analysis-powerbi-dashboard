📊 Tech Layoffs & Hiring Analysis Dashboard (Power BI)

📌 Project Overview

This project is a Power BI dashboard that analyzes tech industry layoffs and hiring trends. It provides insights into workforce changes across companies, industries, and countries.

The dashboard helps users understand:

Which companies are laying off employees
Which industries are most affected
Hiring vs layoffs trends over time
Key factors influencing layoffs

🎯 Objectives
Analyze total layoffs and hiring trends
Identify top companies with layoffs
Compare industry-wise performance
Understand geographical impact
Use AI visuals (Key Influencers & Decomposition Tree) for insights

📂 Dataset
Source: Tech Layoffs & Hiring Dataset
Format: CSV
Fields used: Company, Industry, Country, Date, Layoffs, Hiring

📊 Dashboard Features

🔹 KPI Cards: Total Layoffs, Total Hiring, Total Companies

🔹 Visualizations Used
📈 Line Chart → Hiring vs Layoffs Trend
📊 Bar Chart → Top Companies by Layoffs
🍩 Donut Chart → Industry Distribution
🌍 Map → Country-wise Layoffs
📋 Table → Detailed Data View

🔹 AI-Powered Visuals
Decomposition Tree: Used for root cause analysis, Drill-down by Industry → Company → Country
Key Influencers: Identifies factors driving high layoffs, Provides AI-based insights

🧮 DAX Measures Used
Total Layoffs = SUM('Table'[Layoffs])

Total Hiring = SUM('Table'[Hiring])

📌 Key Insights
Certain industries show higher layoff trends
Some companies dominate layoff counts
Hiring trends fluctuate over time
Geographic regions vary in impact

🛠️ Tools & Technologies
Power BI Desktop
DAX (Data Analysis Expressions)
Power Query (Data Cleaning)




🚀 How to Use
Download the .pbix file
Open in Power BI Desktop
Explore using filters and slicers
Interact with visuals for insights
